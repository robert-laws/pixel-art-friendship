# BYTE vs NULL — a pixel-art short made entirely with code

Two Mega-Man-style robots fight the final boss battle of their game. They hit each other on the same frame,
the game has no case for a tie, and it crashes. Stuck in the debug void, the rivals have to sit down at a terminal, read the
code, and fix it — together (one types, the other watches over their shoulder). About one minute; 1280×720, 30 fps, stereo.

▶ **`out/byte-vs-null.mp4`** is the finished video (16:9, ~67 s).
▶ **`out/byte-vs-null-story.mp4`** is the **Instagram Story** cut (9:16, 1080×1920, ~56 s). See below.
Story and dialogue: [`SCRIPT.md`](SCRIPT.md).

Everything you see and hear is generated by code in this repo, except the dialogue, which was generated with
**ElevenLabs Eleven v4** (the takes are checked in under `assets/voice/`).

| Piece | How |
|---|---|
| Pixel art | Characters are drawn procedurally (paper-doll parts + auto-outline) at 320×180 and integer-upscaled 4× (`friends/characters.py`, `friends/world.py`) |
| Parallax | Six scrolling layers (sky/sun, clouds, two skylines, girders, floor) + lamp posts + a fast foreground cable layer |
| Glitch | Slice displacement, RGB split, block corruption, hall-of-mirrors smear, layers that desync, missing-texture layers, static sky (`friends/fx.py`) |
| Music + SFX | Synthesised chiptune (pulse/triangle/noise) in numpy, no samples (`friends/chiptune.py`). The minor-key battle theme returns in a major key for the ending |
| Dialogue | 21 lines, 2 voices, Eleven v4 audio tags (`assets/voice/manifest.json`) |
| Timing | Every cue is derived from the real voice-line lengths (`friends/timeline.py`), so re-generating a take re-times the whole film |
| Mix | Voice panned slightly L/R, music ducked under speech, loudness-normalised to −16 LUFS (`friends/mix.py`) |

## Build it

```bash
pip install -r requirements.txt     # numpy, pillow, imageio-ffmpeg (bundles ffmpeg)
python build.py                     # -> out/byte-vs-null.mp4   (~2 min)
python build.py --format story      # -> out/byte-vs-null-story.mp4  (Instagram Story, 9:16, <60 s)
python build.py --audio-only        # just the mix
python build.py --max-seconds 20    # quick preview
```

The title and end cards say **"MADE WITH CLAUDE"** by default. To name a specific model version
in those two cards, pass it in:

```bash
python build.py --credit-model "<model name>" --out out/byte-vs-null-credited.mp4
```

## Instagram Story cut

`python build.py --format story` renders a portrait version made for Instagram Stories
(it is re-staged for 9:16, not a crop of the widescreen film):

| | |
|---|---|
| Frame | 1080×1920 (9:16), 30 fps, H.264 High + AAC stereo, −16 LUFS, `faststart` |
| Length | **55.5 s** — under the 60 s per-Story-card limit, with a few seconds of margin |
| Safe zones | Instagram's header covers ~250 px at the top and the reply bar / ad CTA ~340 px at the bottom. HUD, captions, titles and credits all sit between art rows 42 and 263 (of 320) |
| Canvas | 180×320 pixel art upscaled 6× (the widescreen cut is 320×180 at 4×) |
| Re-staging | Stacked `BYTE / VS / NULL` title, taller parallax city, narrower boss bars, 3-line captions, a code window sized for portrait, "PLAYER 2 / HAS JOINED!" on two lines |
| Cuts | Four optional beats are dropped (`07` sky-made-of-static, `09`/`10` "Can it DO that?!" / "Evidently.", `12` "Character growth"); intro, transitions and credits are tightened. Every setup and punchline stays |

Specs checked against current Instagram Story guidance: 1080×1920, up to 60 s per card, H.264 + AAC, 30 fps.
The file is ~30 MB (Instagram accepts far larger).

## Dialogue notes (Eleven v4)

* Model `eleven_v4`, one take per line. Voices: **BYTE** = `VALF - Anime Protagonist Charismatic`,
  **NULL** = `Cavendish` (reported as "Rai" in the generation metadata). Prompts, with their audio tags, are in
  [`assets/voice/manifest.json`](assets/voice/manifest.json).
* Direction is done with tags (`[shouting]`, `[sighs]`, `[flatly]`, `[muttering]`, `[laughing]`, …), CAPS for
  stress, and ellipses for hesitation. Byte is the earnest one; Null gets short, flat lines.
* The first pass ran ~58 s of speech. Seven lines were re-written shorter and re-generated (about 1¢ each), then
  leading/trailing silence and over-long internal pauses were trimmed and each speaker levelled
  (`friends/voice.py`) — the voices themselves are untouched.
* **Heads-up:** the Eleven v4 blog page was blocked by this environment's network policy, so the tag choices are
  based on search summaries of the v4 docs plus v3 conventions rather than the full "Prompting Eleven v4" page.

## Layout

```
build.py            one-command render (frames -> ffmpeg pipe, audio mix, mux)
friends/
  timeline.py       cue times from voice durations (full cut + shorter Story cut)
  scenes.py         choreography for every scene, 16:9 cut (Film.frame(t), Film.events())
  story.py          the 9:16 Instagram Story cut (StoryFilm), re-staged for portrait
  characters.py     BYTE / NULL sprite generator (poses, expressions, lip-flap)
  world.py          parallax arena (dusk + dawn) and the debug void
  props.py          desk, chair, step stool, CRT monitor + code hologram
  fx.py ui.py font.py gfx.py   glitch/CRT effects, HUD + captions + terminal, 5x7 font, pixel helpers
  chiptune.py mix.py           music/SFX synth and the final mix
  voice.py          load / trim / level the Eleven v4 takes
assets/voice/       the generated dialogue (mp3) + manifest
out/                rendered videos (byte-vs-null.mp4, byte-vs-null-story.mp4)
```
